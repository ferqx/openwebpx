## Agent 质量验收与架构解耦 (2026-03-21)

- **摘要**: 建立了一套完整的 Agent 性能评测（Benchmark）与遥测（Telemetry）系统，并实现了项目与 `aegra_api` 的架构解耦。
- **原因**: 为了量化 Agent 的任务成功率并建立“开发-验证-优化”的闭环，同时提升项目的独立性和可维护性。
- **影响**:
    - **评测系统**: 新增 `tests/benchmark/tasks.json` 和 `scripts/run_eval.py`，支持 `make benchmark`。
    - **遥测系统**: 新增 `ToolTelemetry` 数据库模型及配套的 FastAPI 接口 (`/api/telemetry/stats`, `/api/telemetry/logs/{thread_id}`)。
    - **基础设施**: 固化 `Dockerfile.agent` 中的工具链（pnpm, pytest, ruff），修复环境引导失败问题。
    - **架构解耦**: 引入 `app/core/` 抽象层（database, settings, auth），降低了对 `aegra_api` 的直接依赖。
    - **Agent 增强**: `PatchFilesystemMiddleware` 增加模糊匹配建议功能，Prompt 增加环境自愈逻辑。
- **验证**: 通过 `make benchmark` 验证 L1-L3 任务成功率从 50% 提升至 100%。
