# 产品愿景与 V1 目标

## 1. 产品定位
sandbox-agent 是一个面向开发者的任务式 AI 协作台。用户从门户发起任务，进入任务详情持续对话，系统流式返回结果并展示工具执行过程。

## 2. 核心价值
- **任务驱动**：将复杂的 AI 协作结构化为具体的“任务”和“线程”。
- **透明执行**：不仅展示对话结果，也展示 AI 调用的工具、执行的 Shell 以及环境初始化的全过程。
- **SCM 深度集成**：直接连接 GitHub/GitLab 仓库，让 AI 能够基于真实代码上下文进行工作。

## 3. V1 目标
- **主链路闭环**：创建任务 -> 跳转详情 -> 流式回复 -> 可取消/可删除。
- **会话连续性**：离开详情后仍可在门户看到运行状态，重新进入继续查看。
- **工具展示可读**：重点展示调用结果，减少冗余的技术噪声。

## 4. 非目标 (V1)
- 不做归档功能。
- 不做复杂的团队权限体系与协作管理。
- 不做多里程碑的项目管理。

## 5. 核心场景
- **需求发起**：输入 Prompt，选择仓库分支，创建任务并立即开始交互。
- **持续追踪**：在任务详情实时查看 AI 流式回复与工具调用。
- **列表管理**：在门户列表管理所有活跃和已完成的任务，支持状态查询与删除。
