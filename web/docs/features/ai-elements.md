# AI Elements 组件库

本项目在 `src/components/ai-elements/` 目录下封装了一套专为 AI 协作场景设计的原子组件库。这些组件遵循高度可组合的模式，旨在为复杂的 AI 交互提供一致且美观的视觉体验。

## 1. 核心组件概览

### 基础消息类
- **`Message`**: 消息气泡的基础容器。
- **`Conversation`**: 对话列表容器，处理消息流的组织。
- **`PromptInput`**: 支持附件、多行输入的 AI 专用输入框。

### 工具与状态类
- **`Tool`**: AI 工具调用的展示组件。
- **`ToolBar`**: 工具栏容器。
- **`Loader`**: 专门用于 AI 生成或加载状态的占位符。
- **`ChainOfThought`**: 展示 AI 思维链条/推理过程的组件。

### 环境与执行类
- **`Terminal`**: 模拟终端输出，展示 Shell 执行结果。
- **`Sandbox`**: 代码沙箱执行环境的预览与交互。
- **`EnvironmentVariables`**: 环境变量配置与展示。

### 视觉反馈类
- **`Shimmer`**: 骨架屏加载动画。
- **`Artifact`**: 独立于对话流的中间产物（如文件、代码片段）的展示容器。

## 2. 使用原则
- **原子性**: 尽量保持组件职责单一，通过组合实现复杂功能。
- **自适应**: 所有的 AI Elements 均应支持暗黑模式和响应式布局。
- **业务无关**: 组件应仅关注 UI 与基础交互，通过 Props 注入业务逻辑或状态。

## 3. 示例场景
- **工具调用详情**: 使用 `Tool` 组件包裹 `Terminal` 或 `CodeBlock` 来展示 AI 的执行细节。
- **思维链推理**: 在 `AssistantMessage` 中嵌入 `ChainOfThought` 组件展示 AI 的思考逻辑。
