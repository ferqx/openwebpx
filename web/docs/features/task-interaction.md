# 任务对话与交互

## 1. 消息列表
对话流由不同类型的消息组成：
- **User Message**: 用户发出的指令或追问。
- **Assistant Message**: AI 的自然语言回复，支持 Markdown。
- **Tool Call Message**: AI 调用的具体工具及参数（如 `shell`, `read_file`）。
- **Tool Result Message**: 工具执行后的输出，通常以 Shell 风格的 Markdown 渲染。

## 2. 交互逻辑与流式渲染
- **流式显示**: AI 的回复通过 SSE/流协议实时追加到当前会话。
- **工具结果折叠**: 默认折叠已完成执行的工具结果，避免信息过载，用户可手动展开查看。
- **自动滚动**: 当有新消息进入且用户在底部附近时，自动吸附底部；否则保持当前浏览位置。

## 3. 环境初始化展示
会话顶部固定展示环境初始化状态：
- **步骤**:
  - 创建容器
  - 拉取代码 (Clone Repository)
  - 准备环境 (Install dependencies, Boot)
- **约束**: 无论会话如何演进，初始化信息块始终保留在顶部，直至下一次“重置初始化”发生。

## 4. 状态控制
- **发送**: 在对话底部输入框按 Enter 或点击发送。
- **停止 (Stop)**: 在 AI 生成中，发送按钮变为停止按钮。点击后会：
  1. 中断前端流。
  2. 发起后端 `POST /cancel` (thread 级) 停止后端执行。
