- 2026-03-14（任务详情消息区增量渲染优化 + 工具输出瘦身）：
  - 任务详情消息列表新增“按轮次加载更早消息”能力，默认仅保留最近若干轮渲染，并在加载更多时保持滚动位置稳定，降低长线程下的首屏 DOM 压力与历史消息展开抖动。
  - 会话流式阶段新增底部跟随锁释放控制：回复中仅在用户原本接近底部时保持自动跟随，回复结束后主动释放 sticky 状态，避免历史工具链展开/收起时被错误拉回底部。
  - 文件变更摘要改为仅在当前轮最终 assistant 总结落位后插入，避免工具链尚未完成时摘要卡片提前出现在中间过程消息下方。
  - 工具链展开内容改为按需合并与延迟挂载；工具任务项展开时主动停止底部自动滚动，并为非 diff 工具增加显式执行状态徽标，减少长输出场景的重渲染与视觉跳变。
  - `execute/ls` 工具输出新增结构化壳层裁剪：优先提取真实 `Output` 正文、保留成功/失败状态，避免把 `Exit code/Truncated` 包装字段原样暴露到消息正文。
  - `ThreadChatDiffViewer` 与 `shiki` 高亮器改为懒加载，降低任务详情首屏进入与工具详情展开时的同步开销；diff 语言识别补充 `scss/less`。
  - 新增定向单测，覆盖“当前轮是否已落最终 assistant 总结”与结构化 shell 输出裁剪回归。
