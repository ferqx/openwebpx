## 代码审查详情页移除门户 Header 并压缩顶部摘要 (2026-03-27)

- **摘要**: 调整独立 `review` 详情页首屏结构，移除门户级 header 导航区，并将顶部摘要压缩为更紧凑的两行状态卡，让 findings 内容更快进入视野。
- **原因**:
  - 独立详情页继续复用门户 header 会引入额外导航噪音，弱化“当前正在看一条审查结果”的单页语义。
  - 顶部摘要区此前垂直占位偏高，进入页面后评审报告内容被压得过低，阅读效率不足。
- **前端影响**:
  - web/src/pages/review-detail.tsx 移除 `PortalHeader`，保留返回入口、标题说明和单张摘要卡。
  - web/src/pages/review-detail.tsx 将摘要卡改为两行紧凑布局：第一行展示仓库名、运行状态和模式；第二行展示 provider、Review 编号、MR/PR 编号、发现数、待审批修复数与线程状态。
- **测试**:
  - web/test/pages/review-detail-page.test.ts 新增源码级断言，锁定详情页不再渲染 `PortalHeader`，并继续覆盖紧凑摘要的关键文本结构。
- **验证**:
  - `pnpm --prefix web exec node --test test/pages/review-detail-page.test.ts`
  - `pnpm --prefix web test:hooks` 目前仍存在 2 个与本次改动无关的既有失败：
    - `getCodeReviewEmptyStateMessage handles loading, missing repo, and filtered empty states`
    - `portal toolbar action switches between search and settings`
