# 门户与任务管理

## 1. 任务创建面板
用户在门户顶部输入框（Prompt Panel）输入指令并提交：
- **必选参数**: Prompt, Repository, Branch。
- **可选参数**: Model, SCM Provider (GitHub/GitLab)。
- **交互流程**: 提交后前端向后端发起任务创建请求，获得 `thread_id` 后自动跳转至任务详情页。

## 2. 任务列表
列表展示所有已创建的线程：
- **状态映射**:
  - `starting`: 环境初始化中。
  - `running`: AI 正在执行或思考中。
  - `completed`: 上一轮对话已完成，等待用户追问。
  - `stopped`: 已手动中断或执行取消。
- **操作**:
  - **搜索**: 支持按任务名称或 ID 模糊搜索。
  - **取消**: 对 `running` 状态的任务，点击取消将发起线程级取消请求。
  - **删除**: 彻底移除任务（仅在 hover 状态下显示删除按钮）。

## 3. 体验优化
- **加载态**: 首次进入门户会拉取任务列表，显示骨架屏。
- **轮询**: 门户列表会对 `starting/running` 状态的任务进行短周期轮询，保证实时反馈执行进度。
